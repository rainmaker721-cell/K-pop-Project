# K-Pop Display

실물 K-Pop 포토카드를 스캔하고, 스캔된 이미지를 대형 Android 패드에 몰입형 전체화면으로 전시하기 위한 제품 앱의 복원 버전입니다. Vision 프로젝트와는 별개의 제품입니다.

이 저장소의 GitHub 원본에는 `.gitignore`만 남아 있었습니다. 현재 코드는 과거 개발 대화에서 확인된 요구사항과 중단 지점을 바탕으로 다시 구성했으며, 확인되지 않은 USB 스캐너 SDK나 AI API 동작을 임의로 구현하지 않았습니다.

USB 스캐너 장비와 `UsbScannerGateway` 구현체는 후속 단계에서 선정합니다. 현재 Android 앱은 테스트 이미지 입력으로 전체 제품 흐름을 실행할 수 있으며, 장비가 정해지면 `feature-scan` 모듈만 연결하면 됩니다.

## 현재 동작하는 기능

- 포토카드 스캔을 중심으로 구성한 시작 화면
- 기본 데모 포토카드 3개와 최근 스캔 목록
- 실제 스캐너 연결 전 흐름 검증을 위한 단일 이미지 테스트 스캔
- 가져온 이미지 URI 권한 및 목록 유지
- 테스트 스캔 직후 `디스플레이 준비중`을 거쳐 대형 패드 전시 화면으로 자동 전환
- 상태바·내비게이션 바를 숨기는 몰입형 전체화면
- 원본 비율을 유지하는 검정 레터박스 표시
- 두 손가락 확대·축소(1~5배), 이동 경계 제한, 더블 탭 확대/초기화
- 회전 후 선택 화면과 확대 상태 유지
- 시스템 뒤로가기를 차단하고 하단의 작은 버튼으로만 목록 복귀
- 전시 검증을 위한 8초 간격 데모 재생
- 고해상도 로컬 이미지의 축소 디코딩으로 메모리 사용 제한

## 프로젝트 구조

```text
app/                앱 진입점, 화면 상태 및 기능 조립
core/               공통 이미지 모델, 확대/이동 계산
feature-scan/       로컬 이미지 카탈로그, 향후 USB 스캐너 경계
feature-upscale/    업스케일 처리 경계와 안전한 로컬 통과 구현
feature-display/    갤러리, 준비, 몰입형 전시 UI
feature-admin/      전시 간격·최대 배율 설정 모델
docs/               복원 조사 및 잔여 작업 보고서
```

## 실행 방법

필요 환경은 Android Studio의 JDK 17 이상과 Android SDK 36입니다.

```powershell
.\gradlew.bat assembleDebug
```

생성되는 APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

테스트와 정적 검사를 함께 실행하려면:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug
```

## 아직 연결이 필요한 기능

- 실제 USB 포토카드 스캐너 제조사 SDK 또는 USB 프로토콜 구현
- 외부 업스케일 API의 주소, 인증, 과금·재시도 정책
- 온디바이스 업스케일/SLM 모델 및 기기 성능 기준
- 암호화 저장소·DRM 정책
- 숨김 관리자 메뉴와 운영 로그 수집
- 실제 27인치 패널의 해상도·터치·장시간 구동 검증

상세 대조 결과는 [복원 보고서](docs/RECOVERY_REPORT.ko.md)를 참고하세요.
